Maple Friends + Maple · 网页联机

Browser multiplayer · 浏览器联机试玩

Play with friends and Maple. Practice English while you explore.

Open this link, type your name, create a room or join a friend's code. Up to 4 players share one island. Maple greets you and invites short English play. No Java, no Minecraft client, no API key on the page.

Share the room code so classmates can join the same world.

点开链接 → 输入昵称 → 创建或加入房间 → 在浏览器里一起玩。不需要安装 Java / Minecraft。

流畅自测请用本机：在这台 Mac 上打开 http://127.0.0.1:47821/ （localhost）。公网隧道适合给同学联机，延迟更高，画面也可能更卡。

How to play

  1. Enter your name. Create a room, or join with a 4-letter code.
  2. Share the room code. Friends open this same link and join.
  3. WASD to walk, mouse to look, Enter to type English to Maple.
  4. Everyone in the room sees each other move and hears Maple's chat.

Try saying

Hello Maple! Let's build a bridge. follow me what is this block?

怎么玩

  1. 输入昵称。创建房间，或用 4 位房间码加入。
  2. 把房间码发给同学。大家打开同一个链接加入。
  3. WASD 走路，鼠标转头，Enter 用英语和 Maple 聊天。
  4. 同一房间里能看到彼此移动，Maple 的回复大家都能看到。

可以这样说

Hello Maple! Let's dig together. come here how do I craft a pickaxe?

What this demo is

A small shared voxel island in the browser — not Mojang's game. Typing multiplayer first. Classroom Java + Doubao mic stays on the separate Java path. Feedback welcome!

这是浏览器里的共享方块小岛，不是官方 Minecraft。当前版本先做打字联机；Java 版语音陪练仍是另一条路径。欢迎反馈！
